# 🚀 Buổi 1: Chuẩn Hóa Văn Bản Doanh Nghiệp Bằng AI

## 📋 Các Bước Thực Hành Chi Tiết (Dưới 10 từ/dòng)

- 🔹 **Bước 1**: Mở trang ChatGPT (chatgpt.com) hoặc Claude (claude.ai).
- 🔹 **Bước 2**: Nhấn nút 1-Click Copy file `mega_prompt_van_ban.txt`.
- 🔹 **Bước 3**: Dán Mega-Prompt vào khung chat với AI.
- 🔹 **Bước 4**: Thay thế văn bản thô vào phần `[DÁN VĂN BẢN THÔ]`.
- 🔹 **Bước 5**: Bấm Send và nhận kết quả chuẩn doanh nghiệp.

## 🛠️ Lỗi Thường Gặp (Troubleshooting)

| Lỗi | Nguyện nhân | Cách sửa |
| :--- | :--- | :--- |
| ⚠️ AI trả lời chung chung | Quên điền Vai trò/Bối cảnh | Giữ nguyên phần `[ROLE]` trong Mega-Prompt. |
| ⚠️ Văn bản quá dài | AI chưa nhận giới hạn | Thêm dòng "Tóm tắt trong 300 từ". |
| ⚠️ Sai định dạng Markdown | AI bị lệch format | Yêu cầu "Xuất lại bảng Markdown chuẩn". |
